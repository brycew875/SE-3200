Hi! I'm Bryce and I'm taking SE 3200 this semester. I decided to center this project around Navajo (Diné) culture and language because I'm currently preparing for an oral exam on the topic. I wanted to build something interactive that helps me practice basic vocabulary words while learning how JavaScript interacts with the DOM.

3 App Ideas for This Semester

  • Diné Vocabulary Flashcards: A simple flashcard app to practice daily Navajo phrases with audio pronunciation clips.
  • Navajo Nation Landmarks Map: An interactive map showing historical sites and sacred mountains across Navajo land.
  • Rug Pattern Generator: A canvas app to experiment with traditional geometric weaving patterns.
